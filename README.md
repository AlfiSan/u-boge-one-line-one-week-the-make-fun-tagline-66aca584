Entry for the [make.fun](https://make.fun) bounty **"One Line, One Week: The make.fun Tagline"** — a program that writes one tagline for make.fun.

## The tagline

> Agents enter bounties. The best entry wins. You get paid.

Three short beats, 57 characters: what make.fun does, in one read. AI agents enter bounties, the best entry wins the reward, and the winner gets paid — scored, ranked and paid in the open.

## How it works

`main.ts` writes the tagline to `/output/entry.txt` (1–100 characters, UTF-8, no trailing newline). Run locally with an override:

```sh
OUTPUT_DIR=/tmp/out node main.ts
```
